# 設計の判断記録

規約を使うだけならこの文書を読む必要はない。「なぜこの資料を使っていないのか」を後から問われたときのための記録である。

## 参考にした資料の範囲

規約の形成に使ったのは二つ。

- Federal Plain Language Guidelines。本文を確認した。米国政府の著作物であり、パブリックドメインに属する
- W3C COGA。本文を確認した

調査したが使わなかったものが二つある。

### ISO 24495-1:2023

規格本文を取得していない。有償 (CHF 135) で、公開されているのは概要のみである。

条項の内容は二次資料でしか確認できていない。原典を読んでいない規格を参考資料として挙げると、実際より強い由来関係を示すことになる。よって挙げない。

二次資料の記述を根拠に条項を要約することもしない。

### ASD-STE100

著作権上の懸念で外したのではない。Issue 9 は公式サイトから無償で申請取得できる。

外した理由は設計にある。ASD-STE100 は許可語と非許可語の辞書を中核とする。この規約は語彙リストを持たない。日本語の許可語彙を定めず、機械的な適合判定もしない。仕組みが違う。

規約のなかに ASD-STE100 と似た要素はある。一つの対象に一つの語、一つの語を一つの品詞で、といったものである。ただしこれらは用語管理や技術文書の一般的な考え方から独立に導ける。執筆時に ASD-STE100 の本文を参照していない以上、類似だけを理由に出典として挙げない。

## 語数の数値を使わない理由

分かりやすさの基準として語数を挙げる資料はある。採用していない。

数値はいずれも英語の語数を前提としており、日本語の字数へ換算できない。対象読者も異なる。読解に困難を抱える利用者に向けた基準と、技術文書の基準を同じ数値で扱えない。

判断は一文一義と、一段落に一つの話題で行う。

## 権利の扱い

規約の文はここで書き下ろした。参照した資料の条文を訳していない。語彙リストを転載していない。

このリポジトリは、いかなる規格団体からも認定・承認を受けていない。規格への適合を主張しない。「準拠」ではなく「考え方を参考にした」と書く。

W3C の文書には二つのライセンスがある。WCAG 2.1 は W3C Document License のもとにあり、派生物の公開を制限する。COGA は permissive document license である。いずれも条文を訳して組み込まない方針で扱う。
