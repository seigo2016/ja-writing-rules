# ja-report — 報告文の平明化と迅速化

AI から利用者へ作業結果、進捗、調査、要決定事項を伝える文脈に適用する。

規則の本体は `ja-writing-rules` スキルの `reference/reports.md` にある。ここには書かない。

- 結論を最初の一文に置く
- 観測と推測を分ける。推量語尾を使わない
- 強調を絞る
- 確かめていないことを書かない

名詞の連鎖を動詞に開く規則は `ja-writing-rules` の SKILL.md「名詞の連鎖を動詞に開く」にある。

## 報告に固有の規則

報告はシングルパスで出す。執筆のためだけに grep や計測スクリプトを回さず、多段の推敲ループも組まない。進め方の詳細は `ja-prose` の「シングルパス執筆」が決める。

## 具体例 (Before / After)

### 調査報告
- **Bad**: 今回の調査結果について報告いたします。ログの確認を行ったところ、セッション失効処理の遅延が発生している可能性が高いと考えられます。そのため、設定見直し等の対策が必要であると思われます。
- **Good**: セッション失効処理に最大1時間の遅延が発生しています。原因はバッチ同期間隔 (1時間) にあると推測されます。設定間隔を5分に短縮する変更を提案します。

### 判断事項の提示
- **Bad**: 現状では複数案の**検討**を**実施**しており、A案とB案の**比較検証**を行いました。A案は**高速**ですが**メモリ消費**が多く、B案は**低速**ですが**安定**しています。
- **Good**: 処理速度を重視するならA案、メモリ消費を抑えるならB案の採用を推奨します。本番環境のメモリ上限 (4GB) を踏まえ、どちらを適用するか判断をお願いします。
